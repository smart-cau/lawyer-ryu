# `/services` SEO 키워드 맵

> **공통 원칙 상태**: 사용자 합의 완료(2026-07-13)
>
> **페이지별 키워드 상태**: `property-crime`, `corporate-crime`, `general-criminal`, `investigation` 1차 적용. 나머지 URL의 대표·보조 검색어는 페이지 작업 전에 사용자와 개별 합의한다.
>
> 이 문서는 `docs/02-services/01-services-ia-v1.md`의 10개 leaf와 44개 분류를 바꾸지 않는다. 키워드는 기존 IA를 검색 결과와 본문에 어떻게 표현할지 정하는 작성 기준이다.

## 1. 합의한 공통 원칙

### 1.1 키워드의 역할을 분리한다

| 역할 | 기준 | 예시 |
| --- | --- | --- |
| 사건 키워드 | 각 URL의 대표 검색 의도를 정한다. | `창원 투자사기 변호사` |
| 지역 키워드 | 현재 사무소와 실제 상담 지역을 나타낸다. | `창원` |
| 경력 키워드 | 확인된 검사 경력을 신뢰 근거로 사용한다. | `19년 검사 경력`, `검사 출신 변호사` |
| 공식 전문분야 | 등록된 분야를 정확한 명칭으로 표기한다. | `대한변협 등록 형사법 전문 변호사` |
| 검찰 근무 이력 | 현재 서비스 지역과 구분해 경력 문맥에서만 쓴다. | `창원지검과 부산지검 등에서 검사로 근무` |

`창원·부산 검사 출신 형사 전문 변호사`처럼 지역, 경력, 전문분야를 한 문장에 묶어 반복하지 않는다. 현재 사무소의 지역과 과거 검찰 근무지가 섞여 의미가 모호해질 수 있기 때문이다.

### 1.2 `창원`과 `부산`의 쓰임을 구분한다

- `창원`은 법무법인 인유 창원사무소의 지역 서비스 키워드로 제목과 설명에 사용할 수 있다.
- `부산`은 부산지검·부산지검 서부지청 근무 이력을 설명할 때 사용할 수 있다.
- 부산은 실제 상담·수임 타깃 지역으로 확인했다(사용자 확인 2026-07-13). 제목에 사용할 때는 부산 사무소가 있는 것으로 오인되지 않도록 현재 사무소 위치와 구분한다.
- 마산·진해·김해·양산·거제·통영 등 인근 도시를 검색 노출 목적으로 나열하지 않는다.

### 1.3 형사와 비형사 페이지의 경력 표현을 구분한다

- 8개 형사 leaf에서는 `19년 검사 경력`을 제목, 설명, 변호사 소개 중 관련성이 높은 위치에 사용한다.
- 같은 문구를 한 페이지의 제목, 설명, 도입부, FAQ, CTA에 모두 반복하지 않는다.
- `대한변협 등록 형사법 전문 변호사`는 형사 leaf의 변호사 소개에서 전체 명칭을 한 번 명확히 표기한다.
- 민사·가사 leaf에서는 형사법 전문분야를 대표 SEO 키워드로 사용하지 않는다.
- 행정 leaf에서는 음주운전 면허처분, 공무원 징계처럼 형사 절차와 실제로 연결되는 경우에만 검사 경력을 보조 근거로 사용한다.

## 2. 검색 결과와 본문의 배치 기준

| 위치 | 배치 기준 |
| --- | --- |
| `<title>` | 사건명과 `창원`을 우선한다. 경력 키워드는 페이지와 직접 관련되고 제목이 길어지지 않을 때 하나만 넣는다. |
| Meta description | 사건 범위와 의뢰인 상황을 먼저 설명하고 `19년 검사 경력` 또는 검찰 근무 이력을 자연스러운 문장으로 한 번 사용한다. |
| H1 | locked leaf 라벨을 유지한다. 키워드 목록으로 바꾸지 않는다. |
| 상단 도입부 | 검색한 사람이 자신의 사건인지 판단할 수 있도록 상황과 쟁점을 먼저 설명한다. |
| 변호사 소개 | 경력에서 실제 업무 능력으로 이어지는 이유를 설명한다. 공식 전문분야 전체 명칭은 이 위치를 기본값으로 한다. |
| FAQ·CTA | 질문에 대한 답과 다음 행동에 집중한다. 경력 키워드를 채우기 위한 반복은 하지 않는다. |

`meta keywords` 태그는 만들지 않는다. 제목과 설명은 페이지마다 고유하게 작성하며, 본문에 키워드만 나열하는 문단도 두지 않는다.

## 4. 1차 적용안

### 4.1 `property-crime`

- 대표 검색어: `창원 투자사기 변호사`
- 보조 검색어: `보이스피싱 변호사`, `유사수신`, `리딩방 사기`, `횡령·배임`
- 제목: `창원 투자사기·보이스피싱 변호사 | 19년 검사 경력 류남경`
- H1: `재산범죄` 유지
- 경력 문구: `창원지검과 부산지검 등을 거치며 19년간 검사로 근무했습니다.`
- 공식 전문분야: 변호사 소개에서 `대한변협 등록 형사법 전문 변호사`로 표기

### 4.2 `corporate-crime`

- 대표 검색어: `창원 기업범죄 변호사`
- 보조 검색어: `중대재해`, `횡령·배임`, `기술유출·영업비밀`, `조세·금융 범죄`
- 제목: `창원 기업범죄 변호사 | 19년 검사 경력 류남경`
- H1: `기업 관련 범죄` 유지
- 경력 문구: `창원지검과 부산지검 등에서 조세·금융·기술유출 사건을 담당했습니다.`
- 공식 전문분야: 변호사 소개에서 `대한변협 등록 형사법 전문 변호사`로 표기

### 4.3 `general-criminal`

- 대표 검색어: `창원/부산 형사전문 변호사`
- 보조 검색어: `명예훼손·모욕`, `폭행·상해`, `무고`, `사이버 범죄`
- 주된 의뢰인: 고소를 당했거나 경찰 조사를 앞둔 피의자 측. 피해자 안내는 `피해자 고소·피해구제`에서 별도 구획
- 제목: `창원/부산 형사전문 변호사 | 19년 검사 경력 류남경`
- H1: `일반 형사` 유지
- 경력 문구: `19년 검사 경력`을 수사 절차와 증거·진술 정리 능력의 근거로 사용
- 공식 전문분야: 변호사 소개에서 `대한변협 등록 형사법 전문 변호사`로 표기
- 지역 범위: 창원과 부산을 실제 상담·수임 타깃으로 사용하되, 사무소 소재지는 창원으로 구분

### 4.4 `investigation`

- 대표 검색어: `창원·부산 경찰조사 변호사`
- 보조 검색어: `피의자 조사`, `경찰 조사 변호사 동행`, `검찰 조사`, `구속영장실질심사`
- 주된 의뢰인: 경찰 출석 요구를 받았거나 검찰 조사, 체포·구속영장 절차를 앞둔 피의자와 그 가족
- 제목: `창원·부산 경찰조사 변호사 | 구속영장 대응 류남경`
- H1: `조사·구속 대응` 유지
- 경력 문구: `19년 검사 경력`을 진술·자료 검토와 조사 참여 역량의 근거로 사용
- 지역 범위: 창원과 부산을 실제 상담·수임 타깃으로 사용하되, 사무소 소재지는 창원으로 구분

## 5. 페이지 작업 전 합의 항목

각 leaf를 구현하거나 개선하기 전에 다음 항목을 사용자와 확인한다.

1. 해당 URL의 대표 검색어 한 개
2. 보조 검색어 두 개에서 다섯 개
3. 제목에 넣을 지역과 경력 키워드
4. 변호사 경력 중 해당 사건과 직접 연결할 수 있는 사실
5. 피해자·피의자·법인·공직자 등 주된 의뢰인
