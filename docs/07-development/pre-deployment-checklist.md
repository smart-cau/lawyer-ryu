## 1. 사용 방법

이 문서는 발견 사항을 기록하고 배포 여부를 결정하기 위한 작업 도구다. 여기에 항목이 있다는 사실만으로 해당 작업이 자동으로 배포 필수 작업이 되는 것은 아니다. 세부 구현 진행은 기존 원칙대로 GitHub Issues에서 추적하고, 이 문서에는 배포 게이트에 관한 결정과 최종 완료 여부만 기록한다.

### 1.1 상태 값

- **작업 상태**: `미착수` / `진행 중` / `완료` / `해당 없음`
- **초기 제안**
  - `차단`: 완료 또는 명시적 제외 결정 전에는 운영 배포하지 않음
  - `배포 전`: 운영 공개 전에 완료 권장
  - `조건부`: 기능 사용 여부나 사실관계에 따라 필요성 결정
  - `배포 직후`: 운영 공개 직후 처리 가능
- **사용자 결정**: `필수` / `조건부` / `보류` / `제외` / `미결`

사용자 결정이 초기 제안보다 우선한다. `제외` 또는 `보류`로 정한 항목은 결정 이유를 비고에 남긴다.

### 1.2 배포 가능 조건

다음 조건을 모두 만족하면 운영 배포가 가능한 것으로 본다.

- [ ] 사용자 결정이 `필수`인 항목이 모두 완료되었다.
- [ ] 미결 상태의 `차단` 제안 항목이 없다.
- [ ] 운영 환경과 동일한 조건에서 빌드와 데이터베이스 마이그레이션이 성공했다.
- [ ] 대표 연락처, 사무소 명칭, 주소, 상담 시간과 공개 콘텐츠를 류남경 대표변호사가 최종 확인했다.
- [ ] 운영 URL에서 핵심 사용자 동선과 관리자 동작을 점검했다.
- [ ] 장애 발생 시 되돌릴 배포 버전과 데이터베이스 복구 방법을 확인했다.

- **발견 사항**: Payload 이메일 어댑터가 없어 이메일이 콘솔에만 기록된다. 비밀번호 재설정 메일을 실제로 받을 수 없다.
- **결정 사항**
  - [ ] 운영 이메일 어댑터를 구성한다.
  - [ ] 또는 비밀번호 복구 절차를 사용하지 않는다는 운영 결정을 기록하고 대체 복구 절차를 마련한다.
- **완료 기준**
  - [ ] 선택한 복구 절차를 운영 환경에서 검증했다.

## 5. 검색 노출과 메타데이터

### SEO-01. 공식 도메인과 canonical 기준 확정

- **완료 기준**
  - [ ] 공식 도메인을 확정하고 Vercel에 연결했다.
  - [ ] `NEXT_PUBLIC_SERVER_URL`, `canonical`, Open Graph, 구조화 데이터와 사이트맵이 같은 HTTPS 도메인을 사용한다.
  - [ ] Vercel `Preview` 배포는 검색엔진에 노출되지 않도록 했다.

### SEO-02. robots.txt와 사이트맵 수정

- **발견 사항**
  - 사이트맵이 `https://example.com`을 생성한다.
  - 존재하지 않는 `/posts-sitemap.xml`을 참조한다.
  - 사례 사이트맵도 운영 URL이 없으면 `example.com`을 사용한다.
- **완료 기준**
  - [ ] `posts-sitemap.xml` 참조를 제거하고 `cases-sitemap.xml`을 연결했다.
  - [ ] 운영 URL이 없을 때 잘못된 사이트맵을 생성하지 않도록 했다.
  - [ ] `/admin`, Preview, 내부 API와 검색 제외 대상의 `robots` 정책을 확정했다.
  - [ ] 생성된 사이트맵의 모든 URL이 200 응답을 반환하는지 확인했다.
- **관련 코드**
  - `next-sitemap.config.cjs`
  - `src/app/(frontend)/(sitemaps)/cases-sitemap.xml/route.ts`

### SEO-03. 주요 페이지 메타데이터 완성

- **발견 사항**
  - `/services`, `/services/sex-crime`, `/services/anti-corruption`에는 페이지 고유 메타데이터가 없다.
  - `/cases`에는 제목만 있다.
  - 사례 상세의 SEO 제목이 없으면 모든 사례가 같은 기본 제목을 사용한다.
  - 사례 상세 Open Graph URL과 기본 이미지에 Payload 템플릿 잔재가 남아 있다.
- **완료 기준**
  - [ ] 공개 페이지별 고유 제목과 설명이 있다.
  - [ ] `canonical`과 Open Graph URL이 올바르다.
  - [ ] 공유 이미지와 대체 텍스트가 적절하다.
  - [ ] 사례 상세는 문서 제목 또는 승인된 SEO 제목을 사용한다.

### SEO-04. 템플릿 검색 페이지 처리

- **발견 사항**: `/search`가 영어 `Search`, `No results found.`, `Payload Website Template Search` 상태로 공개된다.
- **완료 기준**
  - [ ] 검색 기능을 유지한다면 한글화하고 현재 사례 카드와 연결했다.
