# `/cases` 성공사례 검색 의도·키워드 맵

> **상태: 검토 초안 (사용자 합의 전, 2026-07-20 작성)**
>
> 이 문서는 `docs/02-services/02-services-seo-keyword-map.md`(공통 원칙 2026-07-13 합의 완료)를 상속한다. 지역·경력·전문분야 키워드의 사용 규칙은 그 문서를 따르고, 여기서는 성공사례 글에만 적용되는 원칙을 더한다. 아래 표의 검색어는 전부 **검토 후보**다 — 검색량 데이터 없이 IA·사례 성격으로 만든 가설이며, 사용자 확정 후에만 적용한다.

## 1. 성공사례 글의 검색 의도

서비스 페이지와 성공사례 글은 받는 검색이 다르다.

| | 서비스 페이지 (`/services`) | 성공사례 글 (`/cases`) |
| --- | --- | --- |
| 검색하는 사람 | 변호사를 찾기 시작한 사람 | 자기 상황과 비슷한 **결과가 실제로 있었는지** 확인하려는 사람 |
| 대표 검색 형태 | "창원 성범죄 변호사" | "강제추행 무혐의 사례", "사기 항소심 감형" |
| 글의 역할 | 사건 유형 전반의 안내와 수임 | 특정 결과의 실증. 해당 서비스 페이지로 이어주는 근거 |

따라서 성공사례 글의 대표 검색어는 서비스 페이지의 "지역+사건+변호사" 형태가 아니라 **"의뢰인 언어 사건명 + 결과(+사례)"** 형태로 잡는다.

## 2. cases 고유 원칙

### 2.1 제목은 의뢰인의 언어로, 죄명은 본문에서 정확하게

- 조문식 죄명(예: 아동복지법위반(아동금품유용))은 검색량이 사실상 없다. **title·meta는 의뢰인이 검색하는 말**(아동학대, 사기, 음주운전)로 쓰고, 정확한 죄명·법조는 본문 사건 개요에서 표기한다.
- 제목 공식: `[의뢰인 언어 사건명] [결과] 사례` — 필요하면 절차어(경찰조사, 항소심)를 앞에 더한다.

### 2.2 검색어와 사실이 충돌하면 사실이 이긴다

의뢰인 언어로 바꾸는 과정에서 결과가 부풀려지면 안 된다. 예: id 5는 "아동학대 무혐의"가 검색어로는 좋지만, 실제로 혐의없음을 받은 것은 **금품유용** 혐의이고 학대 혐의는 아동보호사건송치였다. 이 경우 "아동학대 수사 → 형사처벌 없이 종결"처럼 **사실에 맞는 결과어**를 쓴다. 이 원칙은 skill의 하드 규칙(사실관계 불변)·광고규정(결과 과장 금지)과 같은 축이다.

### 2.3 지역·경력 키워드

- `창원`은 title이 아니라 **meta.description**에 기본 배치한다(사례 제목은 사건+결과만으로 이미 길다). title에 공간이 남고 사건 관할과 충돌하지 않을 때만 title에 쓴다.
- 사건 관할(부산 법원, 진주지청 등)은 본문 사실 그대로 두고, 지역 서비스 키워드와 섞지 않는다.
- `19년 검사 경력` 등 경력 키워드를 사례 글에 넣을지는 **합의 항목**이다(§5). 기본값은 사용하지 않음 — 사례 글의 신뢰 근거는 결과 자체다.

### 2.4 배치 기준

| 위치 | 배치 |
| --- | --- |
| title | 의뢰인 언어 사건명 + 결과 (+ 사례). 25~40자 |
| meta.title | title 축약형, 20~28자 (사무소명은 프론트가 자동 부착) |
| meta.description | 상황 → 대응 → 결과 순. `창원` 1회, 대표 검색어 1회 포함. 70~110자 |
| 첫 h2 섹션 첫 문단 | 대표 검색어를 자연스럽게 1회 |
| 본문 마지막(시사점) | 해당 services leaf로 내부링크 1개 |

### 2.5 내부링크: 사례 → 서비스

cases 카테고리 10개는 services leaf와 slug까지 1:1로 같다. 사례 글 시사점 섹션에서 해당 서비스 페이지로 링크해, 사례가 서비스 페이지의 검색 신뢰도를 받쳐주는 구조를 만든다. (서비스 페이지 → 관련 사례 역링크는 services 쪽 작업에서 다룬다.)

## 4. 기존 3건 적용안 초안 (합의 후 일괄 반영)

| 글 | 대표 검색어 후보 | title 초안 | 비고 |

| id 5 아동복지법위반 | 아동학대 혐의없음 | 아동학대 혐의 수사, 형사처벌 없이 종결된 사례 | §2.2 사실 충돌 주의 — "무혐의"를 학대 혐의에 직접 붙이지 않음 |

| id 4 사기죄 항소심 | 사기 항소심 감형 | 사기죄 항소심에서 벌금형으로 감형된 사례 | 현재 title과 근접, 소폭 조정 |

meta.description은 title 확정 후 각 글에서 `창원` 1회 + 대표 검색어 1회를 포함해 다시 쓴다.

## 5. 합의 항목 (사용자 확인 필요)

1. §3 카테고리별 대표·보조 검색어 후보의 채택 여부와 수정
2. §4 기존 3건의 대표 검색어와 title
3. 사례 글에 `19년 검사 경력` 키워드를 쓸지 (기본값: 쓰지 않음)
4. `창원`의 기본 위치를 meta.description으로 하는 §2.3 규칙
5. 내부링크 방향(사례→서비스)과 문구

확정되면 이 문서 머리말의 상태를 갱신하고, `cases-seo-optimizer` skill의 메타 설계 단계가 이 문서를 참조하도록 연결한다.
