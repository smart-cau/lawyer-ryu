# Profile-grounded Positioning

Use attorney experience as evidence for a relevant capability, not as a keyword modifier attached to every paragraph.

## Build a claim ledger

For each candidate claim, record the exact wording, source file or official source, status, page relevance, permitted implication, and prohibited implication.

| Status | Meaning | Action |
|---|---|---|
| `verified` | Corroborated fact and already approved for public use | May publish with accurate wording |
| `approval-needed` | Supported by a source but public phrasing or prominence is not approved | Present as a candidate, do not silently publish |
| `inferred` | Derived from clustering, adjacency, or marketing interpretation | Do not state as fact or specialization |
| `conflicted` | Sources disagree on number, date, name, phone, scope, or wording | Stop and ask the user to resolve it |

Project `docs/` files are research notes by default. A source note, a locked IA, and an approved public claim are different things.

## Relevance test

A profile statement belongs on a leaf only when all are true:

1. the source supports the exact claim;
2. the experience is materially related to the visitor's problem;
3. the copy explains the resulting skill or work, not prestige alone;
4. it does not imply influence, relationships, guaranteed outcomes, or an unregistered specialty;
5. the same proof has not already been repeated without added value.

Use the pattern `experience -> relevant capability -> concrete client benefit`.

Good shape:

- verified experience handling a procedure;
- therefore familiarity with the evidence or decision points in that procedure;
- therefore a concrete action such as preparing a statement, reviewing seizure scope, or organizing an opinion.

Bad shape:

- former prosecutor, therefore knows what prosecutors will decide;
- prosecutor experience repeated as a generic ranking keyword;
- a past assignment turned into a broad `전문` claim;
- `창원 검사 출신` used to imply local relationships.

## Career-to-leaf caution

Directly documented experience may justify more specific positioning. Adjacent or absent experience permits only general, verified capabilities.

- Sex crime: documented sexual-violence trial and related assignment history can support procedure/evidence familiarity after wording approval.
- Corporate/property crime: documented tax, finance, technology-leak, intellectual-property, fair-trade, housing-fraud, and multi-victim work can support only the matching topics.
- Investigation/general criminal: verified investigation, warrant, and trial experience can support procedural capability.
- Anti-corruption, traffic, school violence, civil/family, and administrative pages must not borrow specificity that the profile does not establish. Use general verified credentials or omit the profile claim.

This mapping is a writing guard, not final copy approval.

## SEO guard

Use a credential in a title or description only when it is verified, relevant to that page, readable, and not crowding out the visitor's problem. Do not force `검사 출신`, `19년`, `형사법 전문`, `창원`, and every case keyword into one snippet.

Use `대한변협 등록 형사법 전문 변호사` as the precise credential. Do not transform it into an association-certified specialty in a different field. Keep any non-registered focus wording visually and syntactically separate.
